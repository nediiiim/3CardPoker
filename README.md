# 3CardPoker
A client–server version of the Three-Card Poker game supporting up to eight concurrent players over a socket-based network

• Implemented a multi-threaded server to manage connections, synchronize game state, and broadcast real-time updates to all clients

• Designed a modular OOP architecture for cards, players, betting logic, and hand evaluation to ensure maintainability and scalability

• Built an interactive JavaFX client interface enabling real-time gameplay, bet placement, and result visualization
